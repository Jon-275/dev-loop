- **The merge gate reads a pull request and posts its status (`devloop.gate.reader`).** It posts nothing for a pull request that is closed, goes into another branch than the default one, or comes from a fork with a head a branch of the repository also heads (the rule `devloop labels` uses, now shared as `status_guard.head_of`). After those guards it marks the head pending, reads the changed files by the two commits, checks the list is complete, and posts the verdict. A read that fails ends as a `failure`, never a pass. No command runs it yet.
