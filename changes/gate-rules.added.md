- **The merge gate's lane rules (`devloop.gate.rules`).** A pull request is in the light lane only when every changed file is a regular document that `gate.light` names, with a plain path, and the list of files is complete and no longer than `gate.max_light_files`. Anything else is strict. Hidden files and folders, `devloop.toml`, `devloop/`, agent instructions, build and tool settings, the folders and files `devloop.toml` names and `gate.control` are control files: they are never documents, and a change to one is flagged. Nothing runs the rules yet.
