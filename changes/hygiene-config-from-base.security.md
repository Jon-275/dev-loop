- **A pull request does not choose its own rules.** In `pr-hygiene.yml`, `devloop changes`, `devloop size` and `devloop changelog check` now read `devloop.toml` from the base commit (`--config-from HEAD^1`), so a pull request cannot widen `docs.files`, raise `pr.max_lines`, add to `pr.exclude` or move `changelog.dir` for its own run; a base file that cannot be read fails the check, and only a base with no `devloop.toml` falls back to the pull request's file. A change to `devloop.toml` always counts as code. A change to these rules applies from the next pull request. `pr-hygiene.yml` and `main-health.yml` pin the same uv and Python versions as the other shared workflows.
