- **The merge gate's verdict rules.** A strict pull request passes only when every status in `gate.statuses` and every check in `gate.checks` passed; a failed one is a failure that names it, and one that is missing or not finished is pending. A light pull request passes unless a `gate.light_blocks` status failed. A change to a control file by an author who is not trusted never passes. A status counts only from the workflow account, and a check only from its configured app. Nothing runs the rules yet.
