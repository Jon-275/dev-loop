Mandate: the council's own report is plain, proven and in severity order.
Checks: a verdict that is not stated first; a P0 or P1 with no command and output behind it; a hypothesis presented as a finding; duplicate findings; findings out of severity order.
Severity anchors: P1 = a merge verdict resting on an unproven finding; P3 = wording.
Proof methods: re-run the proof command a finding cites.
Out of scope: the code itself (the other roles review it).
